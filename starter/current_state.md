# บันทึกสถานะโครงการ

นำแบบเปล่านี้ไปไว้ในพื้นที่ส่วนตัว กรอกเฉพาะหัวข้อที่เกี่ยวกับงาน เมื่อมีข้อมูลใหม่ให้แก้สถานะล่าสุดและเพิ่มเหตุผลไว้ในประวัติด้านล่าง

| หัวข้อ | บันทึกของโครงการ |
|---|---|
| ชื่อโครงการและผลที่ต้องการ | |
| เกณฑ์ที่ใช้ตัดสินว่างานเสร็จ | |
| วันที่ทบทวนสถานะล่าสุด | |
| สถานะที่ยืนยันได้ และหลักฐานที่ใช้ | |
| งานถัดไป ผู้รับผิดชอบ และสิ่งที่ต้องรอก่อนเริ่ม | |
| ประเด็นที่ยังรอยืนยัน และวิธีตรวจต่อ | |
| ตำแหน่งของผลงานฉบับใช้งาน | |
| วิธีที่ใช้ ผลที่พบ และสิ่งที่จะนำไปใช้หรือทดลองครั้งหน้า | |

## ประวัติการเปลี่ยนแปลง

เพิ่มหนึ่งแถวเมื่อมีเหตุการณ์หรือการตัดสินใจที่กระทบแผน หากยังไม่ทราบวันที่เกิดเหตุ ให้ระบุว่ารอยืนยัน ช่องหลักฐานใช้ชื่อไฟล์ ฉบับ และหน้าหรือเซลล์ที่เปิดตรวจได้

| วันที่เกิดเหตุ | วันที่รับทราบ | สิ่งที่เกิดขึ้นหรือเหตุผลที่ตัดสินใจ | หลักฐาน | ผลต่องานถัดไป |
|---|---|---|---|---|
| | | | | |
