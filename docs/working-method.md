# วิธีนำ Advisor ไปใช้กับโครงการของตนเอง

ก่อนจัดโฟลเดอร์ ลองเลือกการตัดสินใจที่เกิดขึ้นจริงหนึ่งเรื่อง เช่น “ควรทบทวนเรื่องใดก่อนสอบ” หรือ “ผลทดลองรอบนี้พร้อมนำไปเขียนรายงานหรือยัง” คำถามนั้นจะช่วยกำหนดว่าต้องเก็บหลักฐานอะไร และรายละเอียดระดับใดจึงเพียงพอ

## จากหลักฐานไปสู่การตัดสินใจ

| เทคนิค | วิธีใช้ | ควรใช้เมื่อใด |
|---|---|---|
| อ้างอิงถึงตำแหน่งข้อมูล | จดฉบับของไฟล์ หน้า ย่อหน้า หรือชีตและช่วงเซลล์ พร้อมหน่วยนับ หากได้ผลจากการคำนวณให้บันทึกวิธีคิด | เมื่อนำข้อมูลไปเขียนรายงาน เปรียบเทียบผล หรือใช้ตัดสินใจ |
| บันทึกเหตุการณ์ตามเวลา | เก็บวันที่เกิดเหตุและวันที่ได้รับข้อมูลคนละช่อง หากมีคำยืนยันภายหลัง ให้เพิ่มรายการและระบุว่าเปลี่ยนความเข้าใจเดิมอย่างไร | เมื่อต้องตอบว่าขณะตัดสินใจมีข้อมูลอะไรอยู่บ้าง |
| ทำดัชนีคำค้น | เริ่มจากรายการหัวข้อ ชื่อเดิมหรือชื่อเรียกอื่น และตำแหน่งของต้นฉบับ ถ้าค้นด้วยประโยคยาวไม่พบ ให้ลองใช้ชื่อเรื่องกับคำสำคัญแยกกัน | เมื่อจำได้ว่ามีเอกสาร แต่หาจากชื่อไฟล์ได้ยาก |
| แยกฉบับของเอกสาร | ระบุฉบับที่ใช้อยู่และฉบับที่เคยใช้ หากมีไฟล์ชื่อคล้ายกันมาก อาจเทียบค่า SHA-256 ซึ่งคำนวณจากเนื้อหาไฟล์ เพื่อช่วยระบุสำเนาที่ตรงกัน ส่วนการเลือกฉบับที่จะอ้าง ให้ดูว่าฉบับใดได้รับการยืนยันให้ใช้กับงานรอบนั้น | เมื่อมีหลายสำเนาหรือมีการเปลี่ยนชื่อไฟล์ |
| อ่านตัวอักษรจากภาพด้วย OCR | ใช้ข้อความที่เครื่องอ่านได้ช่วยค้นหน้า แล้วเทียบข้อมูลสำคัญกับภาพ โดยดูหัวแถว หัวคอลัมน์ จุดทศนิยม และหน่วยประกอบ | เมื่อเอกสารเป็นภาพสแกน มีตาราง หรือลายมือ |
| ตรวจคุณภาพการค้น | ลองถามทั้งเรื่องที่รู้คำตอบ เรื่องที่ยังไม่มีหลักฐาน และคำถามใหม่ที่ผู้ใช้ถามจริง ตรวจทั้งคำตอบ ตำแหน่งที่อ้าง และเวลาที่ใช้ค้น | เมื่อเพิ่มแหล่งข้อมูลหรือปรับวิธีค้น |

โครงการขนาดเล็กใช้สารบัญ Markdown กับการค้นในโฟลเดอร์ได้ เมื่อค้นช้าจนกระทบงาน จึงพิจารณาทำดัชนีค้นข้อความในเครื่อง เช่น SQLite ที่รองรับการค้นแบบเต็มข้อความ ดัชนีควรสร้างใหม่ได้จากไฟล์ต้นทาง [วิธีเลือกเครื่องมือค้นและอ่านเอกสาร](tools.md)

## เมื่อเงื่อนไขเปลี่ยน

สมมติว่าผู้รับงานขอเปลี่ยนกำหนดส่ง ให้บันทึกว่ากำหนดใหม่ใช้กับผลงานใด มีผลวันไหน และรับทราบเมื่อใด จากนั้นตรวจงานที่ต้องเสร็จก่อนส่ง ปรับลำดับงานในบันทึกสถานะ และเก็บรายการเดิมไว้ในประวัติ หากพบว่าทุกครั้งต้องตรวจเงื่อนไขเดียวกัน จึงเพิ่มรายการนั้นในคู่มือปฏิบัติงาน

ข้อมูลจากครั้งก่อนช่วยประมาณเวลาหรือเตรียมงานล่วงหน้าได้ ส่วนวันที่จะใช้เป็นกำหนดส่งรอบปัจจุบันควรอ้างจากข้อตกลงของรอบนั้น เมื่อยังรอคำยืนยัน ให้เขียนสิ่งที่ทำเตรียมได้ระหว่างรอไว้ด้วย

## ตัวอย่างการปรับใช้

ตัวอย่างต่อไปนี้เป็นสถานการณ์สมมติ ชื่อไฟล์ วันที่ และจำนวนมีไว้ให้เห็นวิธีบันทึก

### การเรียนด้วยตนเอง

ผู้เรียนตั้งเป้าว่าจะอธิบายค่าเฉลี่ยถ่วงน้ำหนักและเลือกน้ำหนักได้ถูกต้องในโจทย์ที่ไม่เคยเห็น หลังทำแบบฝึกหัด พบว่าคำนวณได้แต่ยังเลือกน้ำหนักผิด จึงเก็บหน้าที่ทำผิดไว้เป็นหลักฐาน แล้วเขียนงานถัดไปว่า “ทำโจทย์เปรียบเทียบกลุ่มที่มีขนาดต่างกัน พร้อมอธิบายว่าเหตุใดจึงใช้น้ำหนักนั้น” เมื่อทำโจทย์ใหม่ได้ตามเกณฑ์ ค่อยเปลี่ยนสถานะเป็นผ่านหัวข้อนี้

### การวิจัยเชิงทดลอง

ผู้วิจัยต้องการรายงานอัตราการงอกของเมล็ดในถาดทดลองหนึ่งถาด วันที่ ๑๒ มีนาคม ผู้สังเกตบันทึกจำนวนเมล็ดที่เพาะ ๑๖ เมล็ด และจำนวนที่งอก ๑๒ เมล็ด ผู้วิจัยได้รับตารางวันที่ ๑๔ มีนาคม จึงบันทึกเหตุการณ์และข้อสรุปดังนี้

| รายการ | บันทึกตัวอย่าง |
|---|---|
| แหล่งข้อมูล | ไฟล์ `seed-trial.xlsx` ฉบับที่ ๑ ชีต `สังเกต` ช่อง `B2` เป็นจำนวนที่เพาะ และ `C2` เป็นจำนวนที่งอก |
| ผลที่ตรวจได้ | ๑๒ ÷ ๑๖ × ๑๐๐ เท่ากับร้อยละ ๗๕ ของเมล็ดในถาดนี้ |
| สถานะที่ผู้วิจัยทราบ ณ วันที่ ๑๓ มีนาคม | ยังรอตารางจากผู้สังเกต |
| สิ่งที่ทำต่อหลังได้รับตาราง | ตรวจหน่วยนับของถาดอื่นก่อนนำผลมาเปรียบเทียบ |

การบันทึกสองวันที่ช่วยอธิบายได้ว่าเหตุใดผู้วิจัยจึงยังรายงานผลไม่ได้ในวันที่ ๑๓ แม้ผู้สังเกตจะนับเมล็ดเสร็จแล้ว

### งานที่มีหลายคนรับช่วง

ทีมจัดนิทรรศการเตรียมภาพสำหรับพิมพ์ ผู้ออกแบบส่งภาพให้ผู้ตรวจแล้ว บันทึกสถานะจึงระบุว่า “ส่งภาพให้ตรวจแล้ว รอผลตรวจสี” พร้อมชื่อไฟล์ฉบับที่ส่ง หากผู้ตรวจขอแก้ ให้จดเหตุผลและส่งฉบับแก้กลับไป เมื่อได้รับคำยืนยันว่าฉบับใดผ่าน จึงส่งฉบับนั้นให้ผู้พิมพ์ คนที่รับงานต่อจะเห็นได้ว่าควรตามผลจากใครและใช้ไฟล์ใด

ทั้งสามกรณีใช้โครงสร้างแฟ้มเดียวกันได้ สิ่งที่ต่างกันคือหลักฐานที่ทำให้ก้าวไปขั้นต่อไปได้ สำหรับผู้เรียนคือคำอธิบายที่ทำได้ด้วยตนเอง สำหรับผู้วิจัยคือตารางที่ตรวจที่มาและวิธีคำนวณแล้ว และสำหรับผู้พิมพ์คือภาพฉบับที่ผ่านการตรวจ
